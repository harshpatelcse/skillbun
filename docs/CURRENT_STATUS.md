# SkillBun current feature status

Updated **30 September 2026**, package version **2.10.63**. This is the maintained feature inventory; it replaces the dated audits, phase plans, and placeholder specifications.

**Implemented** means the feature has a real code path in this checkout. It does not mean all cloud configuration, browser journeys, or live data have been verified. **Partial** identifies a concrete limitation. The **2.10.62 baseline (`6ce1edfe`)** passed GitHub CI and deployed successfully to Vercel Production. Matching Firestore rules were then published to `skillbun-75d10`; live checks confirmed a controlled missing-certificate response and denied unauthenticated raw certificate reads. No live email dispatch or account deletion was performed.

## Completed fixes and remaining verification

Existing-feature repairs are complete where stated below. New features are deferred; cloud/account checks are identified separately.

1. **Account erasure: app and rules deployed; signed-in release verification remains.** Self/admin deletion uses a UID-bound, leased, paginated job with retry checkpoints. Earned roadmap certificates are deleted; workforce/legal records are retained per the owner's decision. Ordinary API access, Firestore client writes and in-flight exam/email writes honor the deletion marker. Tests cover failures, retries, concurrency, identity mismatch, record retention and truthful UI completion. Verify with a disposable approved account; historical orphaned subcollections and backup erasure remain an operations concern.
2. **Credential trust/privacy: app and rules deployed.** Search honors revocation, public lookup uses an explicit allowlist, raw records are owner/admin-only under the published rules, and manual issuance/PATCH preserve existing snapshots. Live missing-ID lookup returns 404; raw unauthenticated Firestore lookup returns 403. Owner dashboard/admin checks with approved accounts remain.
3. **Historical reconciliation: current references checked.** The read-only reconciliation on `skillbun-75d10` at **2026-09-30 11:19 UTC** found 1 certificate, 0 exam attempts and 2 employees, with no mismatched current references. This cannot establish whether older records were deleted along with their references; historical recovery requires backup evidence. No records were changed or reissued. `npm run certificates:reconcile -- --read-only --project <configured-project>` repeats the metadata-only comparison.
4. **Playground execution: repaired.** Opaque sandbox workers keep executable snippets away from app storage and credentials. Static HTML/CSS does not execute scripts; unsupported runtimes are labelled honestly. Sources: `app/components/CodePlayground.jsx`, `utils/server/playgroundSandbox.mjs`.
5. **RAG freshness: completed locally.** Current public corpus and all 821 vectors match. Real local embedding/reranking evaluation passed 8/8; no generative API keys were used. Verify production model startup and resource limits during rollout. See [RAG architecture](rag-architecture.md).
6. **Truthful product claims and search: repaired.** FAQ, account-erasure copy, social-proof claims, SEO and LLM text now match implementation. Search request races and keyboard operation are fixed. Per the owner's choice, saved quiz/chat history, full localization, project submissions and scheduled campaigns are deferred new features.
7. **Retention, consent and recovery.** Set policy for minors, collection/log retention, incident response, analytics, backups and restore testing. Review vendor processing/transfer terms, contact details and credential/outcome wording with the responsible owner; old audit compliance conclusions were not revalidated. Verify the dedicated `HUMAN_PROOF_SECRET` and secret custody, and assess vault-key rotation/source archival without losing decryptability. No rotation, plaintext-source archival, backup restore or live policy validation was performed.
8. **Operational edge cases.** A worker dying after failed Redis invalidation can leave stale mutable caches for their 60-second TTL, or up to 180 seconds under stale reuse when refresh fails. Public certificate verification stays fresh/no-store. Workforce deletion above 500 writes is rejected atomically; the UI now shows archive guidance. Cascades preserve ambiguous academic records and records explicitly linked to another employee. Durable invalidation and larger resumable deletion are separate enhancements. Uncertain email sends require reconciliation, not blind retries.

## Verification evidence

The **2.10.63** local release checks on Node **22.23.3** passed **451/451 tests**, ESLint, template immutability checks and the Next.js **16.3.7** production build. Production smoke passed all 15 HTTP checks, and both deletion endpoints rejected unauthenticated requests. Dependency remediation previously passed a complete audit with no reported vulnerabilities. These results belong to this checkout and are not a blanket security guarantee.

Local browser checks covered desktop/mobile auth UI in both themes. Signed-out quiz navigation redirected to `/auth?next=/quiz`; protected quiz and study-guide endpoints rejected unauthenticated requests. Synthetic certificate checks covered active/revoked search, all four frozen renderers in both themes, mobile overflow, invalid IDs, backend outages and unsupported templates, with no page errors and no real personal data/API requests.

The production-build Playground passed nine browser cases using the actual component and runner with synthetic snippets: JavaScript/promises, JS/Python infinite-loop timeouts, Stop/unmount cleanup, blocked app storage/network/import access, static HTML/CSS sanitization, unsupported-language handling, both themes/mobile layout, real Python math/JSON and controlled download failure. All eight workers closed and no page errors occurred. Search checks covered stale responses, keyboard selection/navigation, IME-safe Escape, desktop/mobile focus, failure display and Tab dismissal; ten rendered routes had correct canonical/noindex metadata. All eight CTA translations and About/Contact FAQ interactions passed desktop/mobile checks in both themes. These checks did not access real accounts or send mail.

Not verified: cloud IAM/indexes/TTL, actual mail delivery, signed-in end-to-end learning/exam/workforce journeys, all guides/videos, production model load/latency, backup restore, or live analytics. Baseline application/rules deployment and unauthenticated certificate checks are verified above. Preview available during this review: **http://127.0.0.1:3000**.
