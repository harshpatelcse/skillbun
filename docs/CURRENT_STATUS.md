## Priorities still open

These are current work items, not claims that the fixes have shipped:

1. **Account erasure: implemented locally; release verification remains.** Self/admin deletion uses a UID-bound, leased, paginated job with retry checkpoints. Earned roadmap certificates are deleted; workforce/legal records are retained per the owner's decision. Ordinary API access, Firestore client writes and in-flight exam/email writes honor the deletion marker. Tests cover failures, retries, concurrency, identity mismatch, record retention and truthful UI completion. Deploy the Firestore rules and app together, then verify with a disposable approved account; historical orphaned subcollections and backup erasure remain an operations concern.
2. **Credential trust/privacy: implemented; deployment verification remains.** Search honors revocation, public lookup uses an explicit allowlist, raw records are owner/admin-only under the updated rules, and manual issuance/PATCH preserve existing snapshots. Tests cover collisions, aliases, ownership, private fields, malformed requests and revocation. Deploy the app before restricting raw reads, then deploy Firestore rules in the same release window.
3. **Historical reconciliation: current references checked.** The read-only reconciliation on `skillbun-75d10` at **2026-09-30 11:19 UTC** found 1 certificate, 0 exam attempts and 2 employees, with no mismatched current references. This cannot establish whether older records were deleted along with their references; historical recovery requires backup evidence. No records were changed or reissued. `npm run certificates:reconcile -- --read-only --project <configured-project>` repeats the metadata-only comparison.
4. **Playground execution.** Resolve sandbox/CSP compatibility and language-label support, then exercise actual browser execution. Do not weaken the site's script policy just to make eval work. Sources: `app/components/CodePlayground.jsx`, `utils/server/contentSecurityPolicy.mjs`.
5. **RAG freshness: completed locally.** Current public corpus and all 821 vectors match. Real local embedding/reranking evaluation passed 8/8; no generative API keys were used. Verify production model startup and resource limits during rollout. See [RAG architecture](rag-architecture.md).
6. **Truthful product claims.** Correct FAQ, account-erasure copy, unsupported social-proof claims, and documentation exposed through SEO/LLM text. Decide whether quiz/chat history, full localization, keyboard search and project submissions should be implemented; they are not complete today.
7. **Retention, consent and recovery.** Set policy for minors, collection/log retention, incident response, analytics, backups and restore testing. Review vendor processing/transfer terms, contact details and credential/outcome wording with the responsible owner; old audit compliance conclusions were not revalidated. Verify the dedicated `HUMAN_PROOF_SECRET` and secret custody, and assess vault-key rotation/source archival without losing decryptability. No rotation, plaintext-source archival, backup restore or live policy validation was performed.
8. **Operational edge cases.** A worker dying after failed Redis invalidation can leave stale values in other workers until expiry. Durable invalidation and workforce deletion above 500 writes require separate designs. Uncertain email sends require reconciliation, not blind retries.

## Verification evidence

The **2.10.62** local release checks on Node **22.23.3** passed **430/430 tests**, ESLint, template immutability checks and the Next.js **16.3.7** production build. Production smoke passed all 15 HTTP checks, and both deletion endpoints rejected unauthenticated requests. Dependency remediation previously passed a complete audit with no reported vulnerabilities. These results belong to this checkout and are not a blanket security guarantee.

Local browser checks covered desktop/mobile auth UI in both themes. Signed-out quiz navigation redirected to `/auth?next=/quiz`; protected quiz and study-guide endpoints rejected unauthenticated requests. Synthetic certificate checks covered active/revoked search, all four frozen renderers in both themes, mobile overflow, invalid IDs, backend outages and unsupported templates, with no page errors and no real personal data/API requests.

Not verified: production deployment, cloud IAM/Firestore rules/indexes/TTL, actual mail delivery, signed-in end-to-end learning/exam/workforce journeys, all guides/videos, production playground execution, backup restore, or live analytics. Preview available during this review: **http://127.0.0.1:3000**.
