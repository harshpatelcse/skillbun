# SkillBun audit remediation — release 2.10.65

This document maps the findings from the 1 October 2026 live audit to the subsequent repairs. The audit checked a broad inventory of pages, routes, controls and catalog data; it did not prove that every possible account state, external destination or security scenario was exercised.

## Release state

**8 October 2026 continuation (local, awaiting release):** the full suite now passes **579/579**, executable Firestore emulator checks **22/22**, and the final built localhost smoke **148/148**, plus lint, build, template and whitespace guards. Production Firestore rules match the local source and all seven declared indexes are READY. Live guide access and below-60% exam rejection passed; reset-email delivery was user-confirmed on 6 October. A fresh-login live deletion attempt exposed rejection of an empty request-body stream; the local bounded stream-validation fix has four new regression cases, but live deletion has not completed. Next and companion packages are patched to 16.3.8; runtime dependency audit is clean. The [current status](CURRENT_STATUS.md#audit-continuation--8-october-2026) and [deployment guide](AUDIT_DEPLOYMENT_HI.md#latest-local-continuation--8-october-2026) supersede the older pending statements below. No production configuration or rules were changed during this continuation.

- **Live repair:** R1, the `www.skillbun.tech` TLS/canonical redirect failure, is repaired. The root URL and a deep link with a query string were checked over HTTPS and returned 308 redirects to `skillbun.tech` with the path/query preserved.
- **Application release:** the repairs below shipped in `2.10.65` and are included in deployed release `2.10.67` (`095aa3ba`). On 6 October, GitHub CI passed and Vercel deployment `dpl_ForpUFhwaTpRvb6SJD9oCRFQUvrr` was verified Production Ready with the apex/www aliases. Post-deployment logs passed 448/448 read-only checks and matched all 100 roadmap JSONs to the release. Later working-tree changes require their own release verification.
- **Firestore release — 3 October 2026:** Firebase CLI successfully compiled and deployed `firestore.rules` to the confirmed `skillbun-75d10` project using `--only firestore:rules`. Functions, indexes and other Firebase services were not deployed. Compiler success does not substitute for the controlled role/ownership execution checks listed below.
- **Local validation:** the final regression suite passed **544/544 tests**, repository lint and the production build passed, and the final built application passed **147/147 read-only smoke checks**, including all 100 roadmaps. The Settings recovery and final verified-email/private-error-header patches are included in this build and test run.
- **Production configuration — 3 October 2026:** after explicit user approval, a new 256-bit random `EMAIL_PREFERENCE_SECRET` was stored as a sensitive Production variable in the existing SkillBun hosting project, and `APP_ORIGIN` was set to `https://skillbun.tech`. Existing secrets were not decrypted or exported, and no secret values were printed or committed. Keep the signing secret stable across deployments.
- **Production checks still needed:** run controlled authenticated smoke checks against the deployed rules. No real marketing message, password reset email, workforce letter, exam or certificate was created merely to verify these repairs.

The original reports are preserved under the `skillbun-audit` artifact folder: `security/security-report.md`, `content/content-audit.md` and `routes/ROUTE-LINK-CONTENT-REPORT.md`. IDs below retain those reports' meaning. C16 is salary-answer grounding; C17 is mobile roadmap category access.

## Rulebook pass

The remediation scope is the reported functional/security/content/accessibility defects and their required compatibility changes. SkillBun assets, branded splash, homepage hero/floating code identity, footer structure and certificate template alignment are preserved. Touched UI continues to use the shared dark/light theme system. Authentication, profile/rule schemas, exam APIs, workforce transitions and abuse controls are intentionally changed for the listed findings; their deployment and remaining validation are explicit above. The normal homepage → onboarding → quiz → recommendation → roadmap journey remains the product flow. The separate [Hinglish deployment guide](AUDIT_DEPLOYMENT_HI.md) describes configuration and rollout steps without exposing secrets.
